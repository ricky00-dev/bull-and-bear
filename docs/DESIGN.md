# 디자인 가이드

> 상태: **확정 2026-11-10, 앱 적용.** B안(다크 그래파이트) + B-7 캐릭터(트레이더 룩, 편 색 넥타이).
> 가안과 원본 에셋은 [design/](design/README.md). 앱 코드 위치는 9절.

## 1. 방향

다크 그래파이트 바탕에 **회색조 + 포인트 한 색**. 화면은 차분하게 두고, 색과 움직임은 캐릭터와 "내가 누를 곳"에만 쓴다.

- 위계는 **명도 단계 하나로만** 나눈다. 테두리와 그림자로 카드를 나누지 않는다.
- 같은 종류는 같은 모양: 카드·칩·버튼·선택지는 각각 한 가지 모양만 쓴다.
- 캐릭터는 정해진 자리에서만 쓴다(5절). 모든 화면을 장식하지 않는다.
- 텍스트만 있는 화면을 줄이되, 그림이 설명을 대신하지는 않는다. 근거·수치·안내 문구는 그대로 둔다.

## 2. 색

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `ground` | `#0B0C0E` | 화면 바탕 |
| `surface` | `#16171A` | 카드, 영상 무대 |
| `surface-2` | `#202125` | 카드 안의 칩·입력·보조 면 |
| `line` | `#26282C` | 목록 행 사이 구분선(카드 경계에는 쓰지 않음) |
| `ink` | `#F2F2F3` | 본문·제목 |
| `sub` | `#A2A5AC` | 보조 문구 |
| `faint` | `#6B6F77` | 비활성·캡션 |
| `point` | `#FF8A3D` (앰버) | 주 버튼 면, 내 선택, 내가 담은 근거, 진행 중 라운드, 라이브 점 |
| `on-point` | `#1B1006` | 앰버 위 글자 |
| `point-soft` | `rgba(255,138,61,.13)` | 선택된 칩·선택지의 면 |
| `up` / `up-ink` | `#E5383B` / `#FF6B6E` | 상승·매수 면 / 글자 |
| `down` / `down-ink` | `#2F6FEB` / `#7AA7FF` | 하락·매도 면 / 글자 |
| `mod` / `mod-soft` | `#A9B3BD` / `#1D2126` | 중재자 글자 / 면 |

- 포인트 색은 **내 행동과 상태에만** 쓴다. 장식·강조 문구에 쓰지 않는다.
- 매수·매도는 색이 아니라 **캐릭터·위치(매수 왼쪽, 매도 오른쪽)·이름**으로 먼저 구분한다.
- 편 색: 캐릭터 넥타이에만 매수 빨강 `#E5383B`, 매도 파랑 `#2F6FEB` (B-7안).
- **결정(11/10)**: ① 화면 포인트는 **앰버 유지**(B-7). ② 시세 등락 숫자와 매수·매도 글자는 **국내 관례색 유지**(상승·매수 빨강, 하락·매도 파랑). 다크 바탕 대비를 위해 글자에는 밝은 변형 `up-ink #FF6B6E`, `down-ink #7AA7FF`을 쓰고, 면(막대·배지)에는 `up #E5383B`, `down #2F6FEB`을 쓴다.
- 대비: 본문 글자는 바탕·카드 위에서 4.5:1 이상. `sub`보다 흐린 색은 본문에 쓰지 않는다.

## 3. 표면·모양·간격

| 층 | 바탕 | 테두리 | 그림자 |
|---|---|---|---|
| 0 바탕 | `ground` | 없음 | 없음 |
| 1 카드 | `surface` | 없음 | 없음 |
| 2 카드 안 요소 | `surface-2` | 없음 | 없음 |
| 시트·모달 | `surface` + 바탕 어둡게(scrim) | 없음 | 없음 |

- 선택 상태만 예외로 안쪽 1px 앰버 선 + 은은한 발광을 허용한다(`inset 0 0 0 1px rgba(255,138,61,.5)`).
- 모서리: 카드 18(`rounded-panel`) · 버튼 12(`rounded-control`) · 칩 10(`rounded-chip`) · 시트 24(`rounded-sheet`) · 아바타 원형.
- 간격: 4의 배수. 화면 좌우 여백 18~20, 카드 안 16, 카드 사이 14, 섹션 사이 24.
- 터치 영역 최소 44×44.
- 고정 하단 바·탭 바는 반투명 바탕 + 흐림(`backdrop-filter`)으로, 선 대신 위쪽 1px 밝은 가장자리로 띄운다.

## 4. 글자

글꼴은 Noto Sans KR 하나. 숫자는 `tabular-nums`.

| 역할 | 크기/굵기 | 줄 간격 | 자간 |
|---|---|---|---|
| 화면 제목 | 25 / 800 | 1.3 | -0.025em |
| 섹션 제목 | 15 / 800 | 1.4 | -0.01em |
| 본문 | 15 / 500 | 1.65 | 0 |
| 보조 | 13 / 400 | 1.6 | 0 |
| 캡션 | 11.5 / 500 | 1.5 | 0 |

다크 바탕이라 본문은 500으로 한 단계 굵게 쓴다.

## 5. 캐릭터

| 캐릭터 | 역할 | 자세 |
|---|---|---|
| 황소 | 매수 AI | 두 발로 서서 손을 들어 짚는다. 밀고 들어가는 설득 |
| 곰 | 매도 AI | 팔짱. 무게로 따지는 회의적인 설득. 둥근 안경(B-7) |
| 부엉이 | 중재자 | 정면, 중립. 은회색 나비넥타이 |

- 재질: 반투명 소프트터치, 몸 안에서 앰버로 빛남. 옷(셔츠·조끼)은 무광. 표정은 반쯤 감은 눈.
- 에셋은 **투명 배경 누끼**만 쓴다. 배경을 칠한 그림을 카드에 넣지 않는다.
- 쓰는 자리와 크기:
  - 홈 첫 화면 히어로: 전신, 높이 약 158
  - 토론 무대: 지금 말하는 쪽 영상(6절)
  - 발언·판정 선택지·결과의 화자 표시: 얼굴 아바타 34~44(원형)
  - 판정 공개·중재자 질문: 부엉이 아바타
- 그 밖의 화면(목록, 설정, 정책 등)에는 넣지 않는다. 한 화면에 큰 캐릭터는 하나.
- **결정(11/10)**: B-7 확정. 상태 포즈(이김·짐·보류)와 빈 화면용 그림은 필요해지면 같은 스타일로 추가한다.

## 6. 움직임·영상

- 기본 전환은 감쇠 1.0 스프링(오버슈트 없음), 응답 약 0.35초. 누르면 0.97로 살짝 줄어든다.
- 모든 애니메이션은 중간에 끊을 수 있어야 하고, 진행 중에도 입력을 막지 않는다.
- 영상은 **화면당 최대 하나**, 무음 8초 루프, `muted loop playsinline autoplay` + 첫 프레임 포스터.
  - 자리: 진행 중 토론의 무대(16:9). 매수 차례엔 황소, 매도 차례엔 곰.
  - 황소: 손을 한 번 짚고 고개를 끄덕이는 짧고 힘 있는 리듬. 곰: 깊게 숨 쉬고 고개를 기울이는 느린 리듬.
  - 영상 배경은 `surface`와 같은 색이라 카드와 경계가 보이지 않는다.
- `prefers-reduced-motion: reduce`이면 영상 대신 포스터, 스프링 대신 짧은 페이드.
- **결정(11/10)**: 영상은 **토론 무대에만** 둔다. 홈 첫 화면은 정지 히어로 이미지(황소·곰 전신).

## 7. 로고·앱 아이콘

- 그림: 이마를 맞댄 황소(왼쪽)와 곰(오른쪽), 맞닿은 이마에서 앰버 빛이 만난다. 원본 `docs/design/app-icon/app-icon-1024.png`.
- 화면 안 로고: 28×28 둥근 사각(모서리 7) + "불앤베어" 18/800. `web/src/components/ui.tsx`의 `Logo`.
- 파일: `web/public/` 파비콘 64, apple-touch-icon 180(불투명, 모서리 없음), PWA 192·512·maskable 512.
- 32px 이하에서는 두 얼굴이 한 덩어리로 보인다. 아주 작은 자리에는 로고 대신 글자만 쓰는 것도 허용한다.

## 8. 하지 않는 것

- 카드마다 다른 테두리·그림자·모서리
- 포인트 색을 장식이나 강조 문구에 쓰기
- 한 화면에 영상 둘 이상, 소리 나는 영상
- 이모지를 아이콘 대신 쓰기
- 배경이 칠해진 캐릭터 그림, 캐릭터를 목록·설정 화면에 장식으로 넣기
- 중재자 판정을 사용자가 판정하기 전에 보여 주는 연출(판정 봉인은 그대로)
