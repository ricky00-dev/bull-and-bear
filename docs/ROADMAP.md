## 결정 사항

PM 기본안으로 진행한다. 이의가 있으면 WORKLOG에 적거나 PR 코멘트로.

| 안건 | 기본안 | 이유 |
|---|---|---|
| 전향 운용 종목 수 | **10개** | 비용. 업종을 고르게 (반도체 2, 2차전지, 바이오, 금융, 자동차, 인터넷, 화학, 통신, 방산) |
| 채점 기준 | 코스피 대비 초과수익, 보류는 ±2%p 이내 | 이미 구현됨. 단순해서 관람객에게 설명하기 쉽다 |
| 코스닥 종목 비교 지수 | 당분간 코스피 | 워커가 코스닥 지수를 아직 못 준다. M2에서 되면 시장별 지수로 바꾼다 |
| 토론 모델 | 토론자 Haiku 5.5, 중재자 Opus 5.5 | 비용 대비 판정 품질. 실험으로 확인 |
| 타임머신 퀴즈 문제 | 7거래일 채점이 끝난 전향 운용 토론 | 첫 문제는 11/4 시작 기준 11/13쯤 생긴다. 더 빨리 쌓으려면 아래 "과거 날짜 토론" 검토 |
