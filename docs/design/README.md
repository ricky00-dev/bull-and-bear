## 지금까지 정해진 것

- **화면 규칙: B안 (그래파이트 글로우)**. 바탕 `#0B0C0E` → 카드 `#16171A` → 칩 `#202125`. 명도로만 층을 나누고 테두리·그림자는 쓰지 않는다. 포인트는 앰버 `#FF8A3D` 하나.
- **캐릭터 후보: B-7**. 앰버 속빛 반투명 몸 + 트레이더 룩(흰 셔츠·차콜 조끼), 넥타이로 편을 나눈다(황소 = 매수 AI 빨강 `#E5383B`, 곰 = 매도 AI 파랑 `#2F6FEB` + 둥근 안경). 중재자 부엉이는 은회색 나비넥타이.
- **앱 아이콘: 맞대결**. 황소(왼쪽)와 곰(오른쪽)이 이마를 맞댄 두 얼굴이 정사각을 반씩 채우고, 맞닿은 이마에서 앰버 빛이 만난다. 원본은 [app-icon/app-icon-1024.png](app-icon/app-icon-1024.png), 생성 지시문은 [app-icon-brief.md](app-icon/app-icon-brief.md), 비교한 후보 5개는 [app-icon/candidates/](app-icon/candidates/).

## 에셋을 만든 방법

- 이미지: Codex 이미지 생성(구독 사용). 스타일은 황소를 먼저 뽑아 고정하고, 그 황소를 기준 이미지로 붙여 곰·부엉이를 맞췄다.
- 영상: Gemini Omni 1.1 Flash, 첫 프레임 = 끝 프레임(같은 스틸 두 장)으로 루프. 720p 16:9.
  - `tools/compose_stills.py`: 누끼를 무대 색 16:9 스틸로 합성
  - `tools/gen_omni.py`: 영상 생성. API 키는 `GEMINI_KEY` 환경변수로만 넘긴다(레포에 없음). google-genai 3.x는 `api_version="v1beta"`가 필요하다(기본 `v1`은 생성 단계에서 404).
  - `tools/finish_video.py`: 배경을 스틸 바탕색으로 고정, 루프 길이 맞춤, 960×540 h264 무음 인코딩, 포스터 추출
  - `tools/prep_cutouts.py`: 누끼 정리(여백·720px)와 얼굴 크롭
- 작은 색 소품(넥타이)은 지시문에 색 이름과 HEX를 적어야 영상 중간에 색이 바뀌지 않는다.

## 알려진 흠

- 앱 아이콘은 32px 이하(브라우저 탭 파비콘)에서 두 얼굴이 한 덩어리로 보인다. 60px 이상에서는 두 얼굴과 표정이 읽힌다.
- `assets/b/video/bull.mp4`: 처음 자세로 돌아오지 않는 테이크라 3.8초 구간 + 0.7초 크로스페이드로 루프. 이음매에서 뿔에 희미한 잔상.
- `assets/d/video/bear.mp4`: 한순간 표정이 놀란 얼굴로 바뀜.
- 가안 페이지의 데이터·문구는 예시다(실제 API 데이터 아님).
