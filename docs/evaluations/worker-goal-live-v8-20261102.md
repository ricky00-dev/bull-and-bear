이번 실행 시점에는 사전 비용 거부가 일반 RuntimeError였기 때문에 LLM 어댑터가 이를 네트워크

요청 장부에는 **실제 보낸 29개 응답의 사용량이 모두 확보**되어 있다. 요청 전 거부는 장부에

실행 종료 후 `LLMRequestBlocked`를 도입해 네트워크 전 거부와 사용량 미확정 실패를 구분했다.
사전 거부는 새 과금으로 기록하지 않고 이전 확인 사용량을 유지한다. 네트워크 타임아웃/응답 누락은
여전히 미확정으로 처리한다. 과거 raw 기록을 수정하거나 현재 수정 결과로 덮어쓰지 않았다.
