최신 v8 토론은 292.570초, 실제 모델 요청 29회다. 요청 장부의 사용량은 모두 확보됐고 미확정 요청은 0이다.
당시 사전 차단을 일반 실패로 처리한 결함 때문에 원본 감사의 `usage_complete=false`, 공개 HTTP usage 누락이
남아 있다. 실행 후 `LLMRequestBlocked`로 처리 경로를 고쳤으며 과거 원본을 수정하지 않았다.
v8 단일은 모델 호출 전 차단됐으므로 단일 분석의 품질 실패로 해석하지 않는다.

HOLD 중재자 반려에는 이미 적힌 유지 가정·위험보다 더 강한 표현을 요구한 것으로 보이는 부분이 있다.
이는 검토 기준이 지나치게 엄격했을 **가능성**이며, 모든 후보가 적절하다는 사람 검수 결과는 아니다.
단일 1회 성공이나 발언 6개 통과는 예측 정확성·반복 안정성을 증명하지 않는다.

## 남은 작업 순서

1. **중재자 검토 기준 점검**: v8 원문으로 관측·가정·위험이 갖춰진 조건부 판단과 근거 없는 인과 주장을 구분한다.
   반려를 없애기 위해 검증을 우회하거나 통과 조건을 임의 완화하지 않는다.
2. **동일 스냅샷 토론·단일 1쌍 완주**: 목표 재개 및 예산·예약 정책 결정 후 실측한다.
   실패 비용도 누적하고, 완주 전 다종목 반복으로 확대하지 않는다.
3. **실모델 Spring·웹 전체 경로 검증**: 현재 통과한 fixture 결과와 구분해 봉인·공개·오류·비용 정산을 확인한다.
4. **예비 운용 대상 확정·설정**: 현재 PC에 Docker가 없고 실제 배포 대상도 미정이다.
   대상이 정해지면 운영 토큰, HTTPS, 영속 경로·비용 장부, PostgreSQL+워커 백업/복원 절차를 적용한다.
5. **소수 종목 반복 검증 후 자동 운용**: 원문 검수·실패율·지연·비용을 확인한 뒤 전향 운용과 단일 비교를 켠다.
   엔진·데이터 조건이 다른 실행을 정식 실험 통계에 섞지 않는다.
