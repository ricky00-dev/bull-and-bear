# FastAPI·워커 운영 준비 계획

2026-10-30. 담당 범위는 `ai-worker/`와 워커 검증 도구다. Spring 공개 계약 변경,
배포 및 전향 스케줄러 활성화는 이번 구현 범위에 포함하지 않는다.

## 순서와 완료 기준

1. 최신 develop(`034d8da`)에 완료된 RAG(`ad8cb26`)를 통합한다.
   데이터 안정화, 비밀값 repr 차단, 테스트 Market 종료 정리와 RAG 설정을 함께 보존한다.
   별도 `rag-hardening` 작업 폴더는 수정하지 않고 검토한 실패 정책·회귀 테스트만 반영한다.
2. 전체 워커 회귀와 실제 로컬 Spring/PostgreSQL/HTTP 연결을 검증한다.
   후자의 시장·모델·시계는 fixture이며 실제 공급자·유료 모델 검증과 구분한다.
   RAG 원문 비공개, 판정 봉인, SSE 재생, 당일 재사용, 채점 예약/실행을 확인한다.
3. 실제 HTTP 경로의 실행 전 점검과 실패 진단을 준비한다.
   모델 역할·키 존재 여부·RAG 상태를 비밀값 없이 확인하고, 실제 모델과 예산이
   확정되기 전에는 유료 호출하지 않는다. 기존 OpenAI 실험 예산을 재사용하지 않는다.
4. 토론 품질 개선은 저장된 실패에서 실제 추론 오류와 검토기 오탐을 분리하는
   재현 가능한 평가부터 진행한다. 기존 반려 규칙을 완료율만 높이기 위해 완화하지 않는다.
5. 소수 종목 전향 운용의 선행 조건과 결과를 기록한다. 실제 데이터/모델 경로,
   기준 가격·정보 관측 시각, 비용·지연·완료율이 확인되기 전 운영 완료로 표시하지 않는다.

## 유지할 조건

- RAG 기본 비활성. 실제 파일럿 1/4 완료·운영 보류 판단 유지.
- HTTP 계약과 공개 이벤트 필드는 유지. 검색 실패 정책은 비공개 감사에 기록.
- 무자료/명시적 시간 초과만 RAG 없이 진행. 무결성·시점·저장 실패는 모델 호출 전 중단.
- 사용자 원본 작업 트리, 다른 작업 폴더, 키와 로컬 실험 원본을 변경하지 않는다.
- 사람 검수 지식집·독립 평가셋·성숙한 3/7거래일 성과는 별도 완료 조건이다.

- 모델 설정/차단/preflight 추가 후 전체 Python: 385 passed, 외부 통합 2 skipped (37.68초).
- 이후 예상 외 응답 모델 차단을 추가하고 영향 범위(LLM/preflight/선공 실험) 12 passed (3.11초).
  앞선 전체 실행 뒤 추가된 테스트 1개가 포함되며 합산해 전체 실행 수로 표시하지 않는다.

  시장·LLM·시계는 synthetic fixture. Java HTTP 클라이언트/채점 단위 7개와 bootJar 통과.

- 공개 계약/Spring·웹 구현 변경 없음. RAG 기본 비활성 유지.

## Claude 모델 정책 및 실제 호출 선행 조건

사용자 지시에 따라 앞으로 운영 모델은 Claude Haiku·Sonnet만 사용한다.
기본값은 기존 compose와 같은 토론자 `claude-haiku-5-5`, 중재자 `claude-sonnet-5-5`다.
공통/역할별 설정 재정의는 유지하되 Opus 등 다른 계열은 SDK 초기화 전에 차단하고,
서버 측 자동 모델 대체도 금지했다. 공급자 응답이 비허용 계열이면 발생한 사용량을
보존한 채 중단한다. CLI·HTTP·Claude 선공 실험의 역할 선택을 일치시켰다.
과거 OpenAI 비교 실행기와 원본 기록은 재현용으로 보존하며 이번에는 실행하지 않았다.

3단계의 비용 없는 점검 명령 `python -m bullbear.preflight --env-file <절대 경로>`를 추가했다.
키 값을 출력하지 않으며 네트워크 호출 없이 모델 설정·키 존재·RAG 설정만 점검한다.
원본 `.env`를 명시해 실행한 결과 `ANTHROPIC_API_KEY` 없음, 개발용 `WORKER_TOKEN`으로
운영 사전 점검이 실패했다. KRX·DART·네이버 설정 존재는 확인했지만 이번 실제 인증은 미검증이다.
사용자는 모바일이라 지금 키 입력이 어려운 상태다. 키 파일을 변경하거나 대화로 수집하지 않았다.

실제 호출 재개 조건:

1. 기존 PC의 `ai-worker/.env`에 사용자가 `ANTHROPIC_API_KEY`를 설정한다.
   이 작업의 별도 worktree에는 `.env`를 복사하지 않았으므로 명시적 환경 로딩이 필요하다.
2. 계정의 모델 목록에서 사용할 Haiku·Sonnet ID와 접근 권한을 확인한다.
   저장소 기본 ID를 실제 접근 확인으로 간주하지 않는다.
3. 첫 HTTP 토론의 총비용 상한을 확정하고 재시도/도구 호출까지 제한 가능한 실행 경로를 준비한다.
   기존 OpenAI USD 3 승인을 Claude 호출에 전용하지 않는다. 이번 유료 호출은 0회다.
4. 운영 전 `WORKER_TOKEN`은 Spring과 같은 비개발용 값으로 설정한다.

4·5단계(독립 라벨 평가/실제 Claude 품질 비교·소수 종목 전향 운용)는 미완료다.
4단계 준비로 오프라인 진단·미라벨 검수 목록 생성기를 추가했다.
기존 파일럿 후보 14건을 추출했으며 절차·집계·한계는 [실패 진단 기록](worker-offline-diagnostics.md)을 참고한다.
실제 Claude 호출은 사용자의 명시적 요청으로 보류하고 비용 없는 작업만 진행했다.
Haiku·Sonnet 실제 호출 완료율을 이전 OpenAI 1/4 파일럿에서 추론하지 않는다.
사람 검수 지식집, 가격 기준일/정보 관측 시각, 코스피 상대수익 근거, 기업행사 보정,
재시작 시 미확정 유료 호출 사용량 복구와 성숙한 3/7거래일 성과도 후속으로 남는다.
