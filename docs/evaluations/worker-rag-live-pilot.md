# gpt-5-mini 공통·단기 RAG 실제 호출 파일럿

2026-10-30. 사용자 승인 모델 `gpt-5-mini`, **이 작업 전체 USD 3** 한도로 실행했다.
같은 승인 원장 `ai-worker/data/rag-p1-live/authorization.sqlite3`와
`rag-p1-20261030-user-approved-3usd`를 모든 조건과 후속 실행에 공유한다.
다른 원장·ID로 예산을 다시 시작하지 않는다. 단가와 예약·미확정 처리 근거는 [예산 평가](worker-model-budget.md).

## 고정한 입력과 해석 범위

원본 키 파일은 복사하거나 출력하지 않고 런타임에서만 사용했다. 읽기 가능한 기존 KRX/OpenDART
캐시를 격리된 데이터 폴더에 복사한 뒤 실제 시장 공급자로 삼성전자 snapshot을 만들었다.
기존 데이터와 사용자 변경은 보존했다. 준비 단계의 모델 호출은 없다.

- snapshot: `005930-20261029-4ff5df3911`
- decision_at: `2026-10-30T18:01:00.094780+09:00`, 가격 기준일: `2026-10-29`
- 시장 Fact: 가격 19, 재무 21, valuation 10, 뉴스 30, 공시 30
- 지식: 출처 연결 AI 자체 설명 6개, 사람 검수 전 experimental
- generation: `G.9a58bb3017422ae082f4644be84062d178ae6e8d2d31a35824d1b6b7601e6311`
- 지식 관측 `2026-10-30T09:00:33.250412Z` 이후 세대를 발행하고 snapshot을 만들었다.
  `observed-v1`으로 당시 발행된 세대만 조회했다.

가격 기준일과 정보 관측 시각에 차이가 있다. 10/30 뉴스가 들어 있는 것은 모델이 미래 뉴스를
만들었다는 뜻은 아니지만, 10/29 종가로 사후 정보를 가진 거래가 가능했다는 주장도 할 수 없다.
KRX 비수정 주가의 기업행사 보정 미구현 경고도 보존했다. 이 입력은 **배경 주입·생성/검증·비용
진단**에 쓰며 실행 가능한 투자 수익률 실증으로 해석하지 않는다.

각 실행은 none/common_short × single/debate의 네 조건이다. 최종 모델과 토론자는 모두 mini,
final effort high/debater medium, bull 선공, 출력 최대 16,000, 조건별 요청 최대 40,
tool turn 최대 4, SDK retry 0, 추가 토론 round 0이다. 사전 파일에 4/4 완료·입력 불변·같은 실제 모델·
공개 근거 경계·공유 예산을 점검 항목으로 고정했다. 운영 p95/완료율 기준을 이 1개 표본으로 추정하지 않는다.

## 실패의 독립 검토

별도 하위 세션이 none 두 조건의 후보·원본 Fact·검토 의견을 대조했다.

- 낮은 PER·이익 규모·하루 동반 하락에서 다음 7거래일 코스피 대비 ±2%p 또는 반등 우위를
  도출한 부분은 추론 비약이다. 제목뿐인 자기주식 처분·배당에서 방식/규모/긍정 수급을 확정한
  부분과 두 공시의 10/29를 29·30일로 나눈 날짜 오류도 있었다.
- single의 2·3번째 후보는 원 단위 시가총액을 본문에 함께 써서 `money_unit` 표시 규칙에서
  반려됐다. 이 두 후보는 의미 검토까지 진행되지 않았으므로 의미적으로 통과한 후보가 아니다.
- `unbacked_number` 경고에는 정책 임계값 ±2%p, 뉴스 원문에 있는 -3.48%/-3.02%,
  변동성 환산 산술값도 들어 있었다. 경고는 단독 실패 원인이 아니며 전체를 실제 수치 날조로 세면 안 된다.
  변동성의 제곱근 시간 환산은 가정이 필요하고 절대 변동성이 상대수익 분포를 대신하지도 않는다.
- 의미 검토가 조건부 주장에 조건 자체의 발생확률을 요구하거나, 수정 예시에서 자기주식 처분과
  취득/소각을 혼동한 사례도 있었다. 검증기 반려를 인간 정답 라벨로 간주하지 않는다.

첫 실행의 raw 오류 코드는 조건별로 unsupported_inference/horizon_mismatch와 money_unit을 포함한다.
원문 후보·검토 원문·실패·사용량은 로컬에 보존하며, 모델/검증기 오류율을 작은 표본에서 일반화하지 않는다.

## 총비용과 운영 판정

두 파일럿 합계 **61회 요청·61회 응답, $0.49036000**, 미확정 요청 0건, 미확정 예약 $0.
승인 상한 $3에서 남은 금액은 $2.50964이며 추가 예산을 요구할 필요가 없었다.
출력 token 수에는 reasoning 비용이 이미 포함되므로 다시 더하지 않았다.
fixture 비용은 이 합계에 포함하지 않았고 미산정 비용을 0달러로 바꾸지 않았다.

**운영 활성화 보류: `BULLBEAR_RAG_ENABLED=false`.** 최종 사전 점검의 4/4 완료 기준을 통과하지
못했고, 운영 p95/완료율/비용 허용 범위를 검증한 대표 표본도 없다. 7거래일 본판정·3거래일 보조의
실제 확정 결과는 없으며 적중률/확신도 보정은 산정하지 않았다. 성숙한 수익률이 없다는 사실과
이번 구현·실행 기록의 완료를 구분한다. P2 위험 검토·LangGraph는 착수하지 않았다.

다음 P1 우선순위는 (1) 실제 추론 오류와 검증기 오탐을 구분한 별도 판정 정답 집합,
(2) 가격 기준일/정보 관측 시각 정합성과 단기 상대수익 근거 보완,
(3) 독립 검색 질문·본문 관련성 검수와 반복 모델 완료율/지연/비용 기준 검증이다.
이번 성공 예시만 골라 재사용하거나 이 파일럿을 보고 같은 정답 집합에 맞춰 통과 기준을 낮추지 않는다.
현재 HTTP 운영 provider 경로는 기존 Anthropic이며, 이번 mini 비교는 별도 benchmark다.
실제 Spring/DB/HTTP 구조 검증의 모델·시장·시계는 fixture였으므로 전체 운영 환경 실모델 통합으로
합쳐 주장하지 않는다. `38a4516` 데이터 안정화 커밋 통합·실제 전향 운용은 별도 후속 작업이다.

## 재현 경로

원문 snapshot/context/원장이 보존된 현재 worktree의 `ai-worker`에서 실행한다.
`OPENAI_API_KEY`는 별도 환경으로 제공한다. 기존 출력은 덮어쓰지 않으며 후속 호출에도 기존
총승인 원장을 사용한다. 아래 명령은 추가 실제 호출을 수행하므로 이미 남긴 결과 열람과 구분한다.

```powershell
python -m bullbear.benchmark `
  --rag-comparison --provider openai --model gpt-5-mini --debater-model gpt-5-mini `
  --allow-paid --max-total-usd 3 `
```
