모델 목록에서 Haiku/Sonnet 접근 가능 여부를 확인한 뒤 `claude-sonnet-5-5`만 호출했다.

- localhost의 실제 Uvicorn HTTP 서버 → POST → 상태 조회 → SSE 경로.
- 입력: 기존 KRX/OpenDART/네이버 스냅샷 `005930-20261028-c637dc2629`.
- 시세 기준일 2026-10-28, 수집 시각 2026-10-29. 최신 시장 재수집은 하지 않았다.
- 단일 분석만 실행. 단일 실행당 API 요청 최대 8회, 출력 최대 4,096토큰/요청,
  도구 루프 최대 4회, SDK 자동 재시도 0회. 금액 상한 검증을 대신하는 설정은 아니다.

처음에는 Claude가 `maxItems`가 포함된 출력 스키마를 HTTP 400으로 거절했다(3요청).
